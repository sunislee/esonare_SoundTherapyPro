- **目标设备**: Redmi K80 Pro (Android 16, API 35)
- **页大小**: 16KB (16384 bytes)
- **内存对齐**: 所有 native 库已适配 16KB 页对齐
- **测试结果**: 无 SIGBUS 错误，无段错误

- **8 轨并发**: 8TrackAudioService 并行加载

- **音频格式**: MP3 (raw 资源)
- **跨平台**: Android (Sound.MAIN_BUNDLE → '') / iOS (Sound.MAIN_BUNDLE)
