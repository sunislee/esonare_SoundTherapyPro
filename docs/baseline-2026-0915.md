- **方案 A（推荐）**：模块级 wrapper 改为纯转发 —— `export const addVolumeListener = (l) => AudioService.getInstance().addVolumeListener(l)`（三个同构），随后删除 `_volumeCallbacks/_timerCallbacks`、`_registerInternalListeners`、`notifyAllSmallScenesListeners`、零调用的 `notifyVolume()`。单一事实源，无双触发风险。
- **方案 B（不推荐）**：真正安装桥接 —— 在 `getInstance()` 末尾调用 `_registerInternalListeners(this)` 并修正 `:4394` 的引用目标。风险：`notifySmallScenes` 被重写后与 `:2476` 叠加 → smallScenes **双触发**，`AudioContext` 会重复 setState。
- 验证方式：改动后需在真机确认「环境音量滑块回显」与「睡眠计时倒数连续刷新」两条链路。
