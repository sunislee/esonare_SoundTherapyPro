# 创建纯净的 1.1.0 提交并推送到 GitHub 计划

## 目标
创建一个没有历史负担的纯净 1.1.0 提交，大小控制在几百 KB，确保 GitHub 能够成功接收。

## 步骤
1. **创建新孤儿分支**：执行 `git checkout --orphan latest_branch`，创建一个全新的、无历史的分支

2. **创建严格的 .gitignore 文件**：
   - 排除所有大文件和不需要的目录，包括 `audio_engine/`、`mobile_app/`、`native_modules/` 等
   - 确保只包含源码文件

3. **手动添加源码文件**：
   - 只添加 `SoundTherapyApp/src/` 目录下的源码文件
   - 添加必要的配置文件，如 `package.json`、`tsconfig.json` 等
   - 确保不包含任何大文件

4. **提交新起点**：执行 `git commit -m "feat: SoundTherapy Pro v1.1.0 (Source Only)"`，创建一个干净的初始提交

5. **替换主分支**：
   - 执行 `git checkout main`，切换回 main 分支
   - 执行 `git branch -D main`，删除本地旧的沉重的 main 分支
   - 执行 `git checkout latest_branch`，切换回干净的分支
   - 执行 `git branch -m main`，将当前干净的分支改名为 main

6. **强制覆盖云端**：
   - 执行 `git push github main --force`，将干净的 main 分支推送到 GitHub
   - 执行 `git push origin main --force`，将干净的 main 分支推送到 Gitee

## 预期结果
- Writing objects 大小应该只有几百 KB
- GitHub 和 Gitee 都成功接收推送
- 两个远程仓库都包含纯净的 1.1.0 代码

## 注意事项
- 此操作会完全重写两个远程仓库的 main 分支历史
- 确保只添加源码文件，排除所有大文件
- 操作完成后，验证两个远程仓库的网页端显示的代码版本为 1.1.0
