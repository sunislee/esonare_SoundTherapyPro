# 执行计划

## 任务 1: 创建 AAB 构建脚本
1. 创建 `scripts/build-aab.sh` 脚本文件
2. 配置脚本内容：
   - 设置 Gradle 并行构建参数 `org.gradle.parallel=true`
   - 配置 JVM 内存为 `-Xmx8g`
   - 实现构建流程：`cd android && ./gradlew clean && ./gradlew bundleRelease`
   - 添加构建成功后绿色高亮打印 AAB 文件路径的功能
3. 赋予脚本执行权限：`chmod +x scripts/build-aab.sh`

## 任务 2: 初始化国际化支持
1. 安装依赖：`npm install react-i18next i18next`
2. 创建目录结构：
   - `src/i18n/locales/`
3. 创建语言包文件：
   - `src/i18n/locales/zh.json`
   - `src/i18n/locales/en.json`
   - `src/i18n/locales/ja.json`
4. 创建配置文件：
   - `src/i18n/index.ts` (i18next 配置)
5. 实现 TypeScript 类型定义，确保翻译 Key 的代码补全
6. 确保在项目入口文件中导入国际化配置
