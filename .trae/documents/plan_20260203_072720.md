## 分支清理计划

### 目标分析
当前仓库中存在三个带有大文件的分支：feat/v1.1.0-immersive、feature/lottie-tabbar 和 feature/scene-logic-refactor，这些分支属于"没用且沉重"的分支，需要被清理以保持仓库轻量。

### 执行步骤
1. **本地分支删除**：
   - 执行 `git branch -D feat/v1.1.0-immersive`
   - 执行 `git branch -D feature/lottie-tabbar`
   - 执行 `git branch -D feature/scene-logic-refactor`

2. **Gitee远程分支删除**：
   - 执行 `git push origin --delete feat/v1.1.0-immersive`
   - 执行 `git push origin --delete feature/lottie-tabbar`
   - 执行 `git push origin --delete feature/scene-logic-refactor`

3. **清理结果验证**：
   - 执行 `git branch -a` 检查所有分支
   - 确认只剩下干净的 main 分支

### 预期结果
- 本地仓库只保留 main 分支
- Gitee 远程仓库只保留 main 分支
- 仓库保持轻量状态，不再包含大文件
- 后续开发只在 main 分支上进行，确保仓库持续保持轻量

### 注意事项
- 使用 `-D` 参数强行删除本地分支，不需要确认
- 使用 `--delete` 参数删除远程分支
- 清理后需要验证结果，确保所有目标分支都已删除
